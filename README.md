# Ruby

Venture into an atmospheric  forest in this focused 2D platformer. Explore  pathways, manage your health, and earn points as you survive.


## Features

- **Atmospheric Environment:** Explore a moody forest beneath the cover of night.
- **Combat:** Fight aggressive wildlife, including relentless boars, using responsive combat mechanics.
- **Health and Survival:** Manage your health and use medical items to survive encounters.
- **Scoring System:** Earn points as you progress through the level.
- **Enhanced Game Feel:** Dynamic particle effects, camera feedback, custom sound effects, and atmospheric background music.
- **Restart System:** Press `Escape` to open the in-game interface and restart or continue your run without refreshing the browser.
- **Safe-Point Respawning:** After death, return to a nearby safe point instead of restarting the entire level.

## Project Status

The first level is complete and playable. This project represents an early milestone in my game-development journey, with room for additional levels, mechanics, and improvements.

## Built With

- **Engine:** Godot Engine
- **Genre:** 2D Platformer
- **Development:** Independent game development with AI-assisted programming

## AI-Assisted Development

I used AI as a programming assistant to help implement selected complex mechanics and work through technical challenges during development.

The AI-assisted work was part of an iterative development process rather than an attempt to generate an entire game without involvement. I directed the intended behavior of the game, worked through implementation challenges with AI assistance, and integrated the resulting code into the project.

This project is also a learning experience in game development, problem-solving, and building interactive systems with Godot.

## Getting Started

### Play the Game

1. Open the [Releases](../../releases) section of this repository.
2. Download the latest Windows build ZIP.
3. Extract the ZIP file.
4. Run the `.exe` file to launch the game.

Keep the `.pck` file in the same folder as the executable if the exported build includes a separate resource package.

### Open the Source Project

1. Install the Godot Engine version used by this project.
2. Clone or download this repository.
3. Open Godot's Project Manager.
4. Import the project by selecting its `project.godot` file.
5. Open the project and run the main scene.

## Controls

- **Escape:** Open the in-game interface to restart or continue your run.
